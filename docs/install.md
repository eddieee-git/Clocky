# 설치 안내

[← README로 돌아가기](../README.md) · [English](install.en.md)

## 요구 사항

- Apple 실리콘 Mac (M1 이상). Intel Mac은 지원하지 않습니다.
- macOS 13 이상. 개발과 시험은 macOS 26에서 했습니다.

## 설치하기

1. [Releases](https://github.com/eddieee-git/mac-app-clocky/releases)에서 `Clocky-<버전>.dmg`(0.2.1까지는 `Clocky.dmg`)를 내려받습니다.
2. dmg를 열고 Clocky를 Applications 폴더로 끌어다 놓습니다. dmg 창에서 바로 열면 dmg를 꺼낼 때 Clocky도 꺼지므로, 꼭 Applications 폴더에서 엽니다.
3. dmg를 꺼냅니다.
4. Applications 폴더에서 Clocky를 실행합니다.

실행해도 Dock에는 아이콘이 생기지 않습니다. 화면 위쪽 메뉴바에 자명종 아이콘이 나타나고 시계 창이 뜨면 정상입니다.

릴리스에 적힌 SHA-256 값으로 내려받은 파일을 확인할 수 있습니다.

```bash
shasum -a 256 ~/Downloads/Clocky*.dmg
```

## 처음 실행할 때 나오는 보안 경고

인터넷에서 받은 Clocky를 처음 열면 macOS가 실행을 막고 경고 창을 띄웁니다. 문구는 macOS 버전에 따라 조금씩 다르며, 대개 Apple이 악성 코드 여부를 확인할 수 없다는 내용입니다.

**왜 나오나요?** macOS는 Apple의 유료 개발자 프로그램으로 서명하고 공증받지 않은 앱을 기본으로 막습니다. Clocky는 무료 프로젝트라 이 인증을 받지 않았습니다. 앱에 문제가 발견되어 나오는 경고는 아닙니다. 다만 Apple이 검사하지 않았다는 뜻은 맞습니다. 믿을 수 있는 곳에서 받은 파일만 여세요. 코드는 이 저장소에 공개되어 있어서 직접 확인하고 [빌드](../README.md#직접-빌드하기)할 수도 있습니다.

### 방법 1: 시스템 설정에서 허용

1. 경고 창에서 **완료**(버전에 따라 **확인**)를 눌러 닫습니다. **휴지통으로 이동**은 누르지 마세요.
2. **시스템 설정 → 개인정보 보호 및 보안**을 엽니다.
3. 아래로 내려 **보안** 항목의 Clocky 안내 옆에 있는 **그래도 열기**를 누릅니다.
4. 확인 창이 나오면 다시 **그래도 열기**를 누르고, Mac 암호나 Touch ID로 승인합니다.

처음 한 번만 하면 됩니다. 새 버전을 설치하면 다시 해야 할 수 있습니다. **그래도 열기** 버튼은 Clocky를 열어 본 뒤 약 1시간만 보입니다.

### 방법 2: 터미널 명령

터미널을 쓴다면 이 명령 하나로 대신할 수 있습니다. Clocky를 Applications 폴더로 옮긴 뒤에 실행하세요.

```bash
xattr -dr com.apple.quarantine /Applications/Clocky.app
```

"손상되었기 때문에 열 수 없습니다"라는 문구가 나올 때도 이 명령으로 풀 수 있습니다.

## 로그인할 때 자동으로 실행하기

**설정 → 일반 → 로그인 시 자동 실행**을 켭니다. Clocky를 Applications 폴더에 둔 뒤에 켜세요. 알람이나 캘린더 알림을 쓴다면 켜 두기를 권합니다. 앱이 꺼져 있으면 울리지 않습니다.

## 캘린더 접근

**설정 → 캘린더 → Mac 캘린더 앱의 일정으로 알림**을 켜면 macOS가 캘린더 접근을 묻습니다. 허용해야 Mac 캘린더 앱의 일정을 읽습니다. 거절했거나 나중에 바꾸려면 **시스템 설정 → 개인정보 보호 및 보안 → 캘린더**에서 Clocky를 켭니다.

## 업데이트

Clocky는 하루에 한 번 GitHub에 새 버전이 있는지 확인합니다. 새 버전이 있으면 메뉴바 메뉴에 **새 버전 Clocky … 받기…**가 나오고, **설정 → 일반 → 업데이트**에도 보입니다. 바로 확인하려면 메뉴의 **업데이트 확인…**을 누릅니다. 자동 확인은 설정에서 끌 수 있습니다.

1. **새 버전 받기…** → **다운로드**를 누릅니다. 다운로드 폴더에 `Clocky 0.x.x.dmg`가 받아지고 열립니다. Clocky는 받은 파일이 GitHub에 올린 파일과 같은지(SHA-256), 만든 사람의 서명이 맞는지 확인합니다. 서명이 없거나 맞지 않으면 받지 않습니다.
2. 안내 창에서 **Clocky 종료**를 누릅니다.
3. 열린 창에서 Clocky를 Applications 폴더로 끌어다 놓아 기존 앱을 대체하고, Clocky를 다시 엽니다.
4. 보안 경고가 다시 나오면 위의 방법으로 허용합니다. Mac 캘린더 연동을 쓰고 있다면 캘린더 접근도 다시 물을 수 있습니다.

0.2.0에는 업데이트 확인이 없으므로, 0.2.0에서는 한 번만 직접 받아서 바꿉니다.

1. 메뉴바 아이콘 → **Clocky 종료**로 앱을 끕니다.
2. 새 `Clocky-<버전>.dmg`를 열고 Applications 폴더로 끌어다 놓아 기존 앱을 대체합니다.
3. 보안 경고가 다시 나오면 위의 방법으로 허용합니다. Mac 캘린더 연동을 쓰고 있다면 캘린더 접근도 다시 물을 수 있습니다.

설정, 알람, 연결한 캘린더는 앱과 따로 저장되므로 그대로 남습니다. Clocky가 받아 둔 dmg가 있으면, 새 버전을 처음 켤 때 휴지통으로 옮길지 묻습니다.

## 문제 해결

**보안 경고가 나오고 열리지 않습니다**
위의 [처음 실행할 때 나오는 보안 경고](#처음-실행할-때-나오는-보안-경고)를 따르세요. **그래도 열기** 버튼은 Clocky를 열어 본 뒤 약 1시간만 보입니다. 버튼이 없으면 Clocky를 한 번 더 열어 경고를 띄운 뒤 다시 가 보세요.

**"Clocky를 Applications 폴더로 옮겨 주세요"가 나옵니다**
dmg 창에서 바로 열었기 때문입니다. Clocky를 종료하고 Applications 폴더로 끌어 놓은 뒤 거기서 여세요. 그래야 dmg를 꺼내도 계속 돌고, 로그인 시 자동 실행도 됩니다.

**메뉴바에 아이콘이 보이지 않습니다**
메뉴바 아이콘이 많으면 노치나 다른 아이콘 뒤로 숨을 수 있습니다. ⌃⌥C를 누르면 시계 창이 열립니다. macOS 26부터는 **시스템 설정 → 메뉴 막대**에서 Clocky가 허용되어 있는지도 확인하세요.

**소리가 들리지 않습니다**
- Mac이 음소거되어 있거나 소리가 블루투스 헤드폰 등 다른 장치로 나가고 있지 않은지 확인하세요.
- **설정 → 소리**에서 소리 크기와 ▶︎ 버튼으로 들어 보세요.
- 소리는 정한 시간(기본 1분)이 지나면 멈춥니다. 창은 끌 때까지 깜빡입니다.

**알람이 울리지 않았습니다**
- 덮개를 닫았거나 Mac이 잠자는 동안에는 울리지 않습니다. 깨어났을 때 지난 지 1시간이 안 된 알람은 바로 울립니다(캘린더 알림은 15분).
- Clocky를 종료해 두었다면 울리지 않습니다. 로그인 시 자동 실행을 켜 두면 좋습니다.
- 알람의 **켜기** 스위치와 반복 요일을 확인하세요.

**캘린더 일정이 보이지 않습니다**
- **설정 → 캘린더**에서 주소 옆에 오류가 나오는지 확인하세요. 주소를 찾을 수 없다고 나오면 비공개 주소를 다시 복사해 넣습니다.
- Mac 캘린더 앱 연동은 **시스템 설정 → 개인정보 보호 및 보안 → 캘린더**에서 Clocky가 켜져 있어야 하고, Clocky 설정에서 그 캘린더를 골라야 합니다.
- 앞으로 이틀 안의 일정만 보입니다. 종일 일정과 거절한 일정은 기본으로 빠집니다.
- iCal 주소는 15분마다 새로 받습니다. 바로 보려면 **지금 새로 받기**를 누르세요.

**업데이트한 뒤 캘린더 접근을 다시 묻습니다**
Clocky는 개발자 인증서 없이 서명해서, 버전이 바뀌면 macOS가 다른 앱으로 볼 수 있습니다. 다시 허용하면 됩니다.

**업데이트 확인이 실패합니다**
인터넷 연결을 확인하세요. 회사 네트워크가 GitHub를 막고 있을 수도 있습니다. 그럴 때는 [릴리스 페이지](https://github.com/eddieee-git/mac-app-clocky/releases)에서 직접 받으면 됩니다.

**전역 단축키가 동작하지 않습니다**
다른 앱이 같은 키를 쓰면 등록되지 않습니다. **설정 → 단축키**에서 표시를 확인하고 다른 키로 바꾸세요.

해결되지 않으면 [이슈](https://github.com/eddieee-git/mac-app-clocky/issues)로 알려 주세요. macOS 버전과 어떤 상황이었는지 적어 주시면 도움이 됩니다.

## 삭제

1. 메뉴바 아이콘 → **Clocky 종료**로 앱을 끕니다.
2. Applications 폴더에서 Clocky를 휴지통으로 옮깁니다.

설정, 알람, 연결한 캘린더, 내 소리 파일까지 지우려면 Finder에서 `~/Library/Containers/com.eddieee.Clocky` 폴더를 휴지통으로 옮기거나 아래 명령을 실행합니다. macOS가 다른 앱의 데이터에 접근해도 되는지 물으면 허용합니다.

```bash
rm -rf ~/Library/Containers/com.eddieee.Clocky
```
